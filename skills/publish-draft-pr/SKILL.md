# Publish Repair PR

Publish the result of a Pipeline Guard remediation without requiring another plugin. This skill
owns only the narrow final step of locating, creating, or reusing the repair draft PR on Bitbucket
or GitHub. It is not a general-purpose pull-request management skill.

## Preconditions

- The remediation was approved through the Pipeline Guard approval contract.
- The incident branch was committed and pushed by `scripts/git_executor.py`.
- The neutral request was generated by `scripts/pr_request_builder.py` with `draft=true`.
- The project configuration declares `repository.provider` as `bitbucket` or `github`.
- Provider credentials are available only through environment variables.

## Execute the deterministic gate

Send only `request`, `incident_id`, `run_id`, and `workspace_path` on standard input:

```bash
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/pr_publication.py" \
  --config "<validated-project-config-path>" \
  < "<publication-request-json-path>"
```

Do not include credentials or a model-declared validation status in the JSON. The command verifies
the pushed branch, re-runs the allowlisted validation commands, evaluates the publication policy,
and only then invokes `scripts/draft_pr_publisher.py`.

## Provider credentials

### Bitbucket

- Required: `BITBUCKET_API_TOKEN`
- Optional: `BITBUCKET_URL` to verify the configured workspace
- Optional: `BITBUCKET_EMAIL` for Personal API Token or OAuth Consumer authentication

### GitHub

- Required: `GITHUB_API_TOKEN`
- Optional: `GITHUB_URL` to verify the configured owner

Never place these values in arguments, prompts, request JSON, logs, or PR content.

## Publication behavior

1. Detect the provider from the validated project configuration.
2. Look for an open PR with the same source branch, destination branch, visible `ID:` and `Run:`.
3. Reuse a matching draft instead of creating a duplicate.
4. Refuse to create another PR when the matching open PR is no longer a draft.
5. Create exactly one draft when no match exists.
6. If the provider ignores `draft=true`, close the created PR and fail safely.
7. Return only the PR `id`, `url`, validation decision, and deterministic test result.

## Prohibited actions

- Do not approve, merge, deploy, rerun the repaired pipeline, or delete branches.
- Do not expose generic issue, repository, reviewer, or pull-request administration operations.
- Do not support providers beyond Bitbucket and GitHub without an explicit Pipeline Guard change.
